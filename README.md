# 🛒 Everyfy - Grocery Shopping App

**Everyfy** is a feature-rich, cross-platform grocery application built to make daily shopping fast, reliable, and user-friendly. Whether users are browsing for daily essentials or managing their monthly grocery lists, Everyfy delivers a smooth interface and seamless backend performance.

## ✨ Key Features

*   **User Authentication:** Secure login and seamless onboarding process.
*   **Dynamic Product Catalog:** Categorized grocery items with detailed descriptions and pricing.
*   **Smart Cart & Checkout:** Intuitive cart management with a streamlined checkout flow.
*   **Order Management:** Real-time order tracking and history.
*   **Push Notifications:** Instant local and push notifications for order updates and promotional offers.

## 🛠️ Tech Stack

*   **Frontend:** Flutter (Dart)
*   **State Management:** GetX / Provider
*   **Backend & Database:** PHP with MySQL (phpMyAdmin)
*   **Cloud Services:** Firebase Messaging (FCM) for notifications
